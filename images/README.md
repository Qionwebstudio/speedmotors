# 이미지 폴더

아래 파일명 그대로 이 폴더에 넣으면 사이트에 자동으로 표시됩니다.
(파일이 없으면 회색 자리표시가 대신 보입니다.)

| 파일명 | 위치 |
|---|---|
| `hero.jpg` | 메인 화면 큰 이미지 |
| `store.jpg` | 매장 안내 사진 |
| `bike-1.jpg`, `bike-2.jpg` … | 매물 대표 사진 (숫자 = 매물 번호) |
| `bike-1-1.jpg` ~ `bike-1-4.jpg` | 상세페이지 사진 (측면·후면·계기판·엔진룸) |

주의: 파일명은 **영문 소문자 + .jpg** 로 정확히 맞춰야 합니다. (`Hero.JPG` ✕ → `hero.jpg` ○)
